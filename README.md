# HomeGrid RU — Android-приложение для локального мониторинга

Русскоязычный Android-проект для чтения телеметрии HomeGrid Monitor и совместимого HTTP JSON API.

## Настроено под текущую сеть
- API по умолчанию: `http://192.168.0.113:18899/api/status`
- Опрос: каждые 2 секунды
- Поддерживаются поля из JSON HomeGrid Monitor: `live.batV`, `live.batA`, `live.soc` / `live.battery_soc.value_pct`, `live.pvTotalW`, `live.outW`, `live.mainsV`, `live.outV`, `live.outHz`, `live.invC`.
- Индикатор ONLINE учитывает `connected` и `available` из корня ответа.
- В настройках можно изменить IP/порт и путь API.

## Экраны
- **Обзор** — солнечная мощность, АКБ, нагрузка, сеть и выход инвертора.
- **АКБ / BMS** — напряжение, ток и SOC; ячейки BMS пока не доступны из этого API.
- **Графики** — демонстрационные графики, это пока не сохранённая история реальных измерений.
- **Настройки** — адрес API, путь и автообновление.

## Ограничения
1. Это исходный проект, а не модификация HomeGrid Monitor.
2. Приложение читает данные из HTTP API. Оно **не подключается напрямую** к регистратору ANENJI `192.168.0.128:8899`; прямой протокол регистратора пока не реализован.
3. Для работы по адресу `192.168.0.113:18899` HomeGrid Monitor должен быть запущен на телефоне, а телефон — подключён к той же локальной сети.
4. Управление настройками инвертора и запись параметров не реализованы.
5. В предоставленном ответе API BMS отключена (`bms.connected=false`), поэтому данные ячеек и балансировки недоступны.
6. Если IP телефона изменится, замените его в настройках.

## Сборка APK без Android Studio
В проект добавлен GitHub Actions workflow: `.github/workflows/android.yml`. Он собирает debug APK в облаке и публикует его как артефакт `HomeGridRU-debug-apk`.

Инструкция для iPhone/iPad находится в [`BUILD_ON_IPHONE.md`](BUILD_ON_IPHONE.md). Сам APK можно установить только на Android, не на iPhone.
