# Как собрать HomeGrid RU APK с iPhone/iPad без Android Studio

## Что делает этот проект

GitHub Actions собирает Android-приложение на облачном сервере. iPhone нужен только для загрузки исходников, запуска сборки и скачивания APK. Сам APK предназначен для Android, а не для iOS.

## Шаг 1. Создайте приватный репозиторий

1. В Safari откройте https://github.com/new и войдите в GitHub.
2. Repository name: `HomeGridRU`.
3. Выберите **Private**.
4. Можно поставить галочку **Add a README file**, затем нажмите **Create repository**.

## Шаг 2. Загрузите файлы проекта

1. Распакуйте исходный архив `HomeGridRU_github_actions.zip` в приложение «Файлы» на iPhone (нажмите архив, чтобы iOS распаковала его).
2. В репозитории на GitHub откройте **Add file → Upload files**.
3. Загрузите файлы и папки проекта из распакованного архива. В корне репозитория должны лежать `settings.gradle.kts`, `build.gradle.kts`, `gradle.properties`, папка `app` и папка `.github`.
4. Если интерфейс iPhone не позволяет выбрать папки целиком, загружайте содержимое отдельными порциями. Обязательно сохраните вложенные пути, например `app/src/main/java/ru/homegrid/monitor/MainActivity.kt` и `.github/workflows/android.yml`. Нельзя загружать всё в одну плоскую папку.
5. Нажмите **Commit changes**.

> Важно: если при создании репозитория вы добавили свой README, при загрузке файлов не заменяйте README проекта, если не уверены. Остальные исходные файлы должны сохранить исходную структуру каталогов.

## Шаг 3. Запустите сборку

1. Откройте вкладку **Actions** репозитория.
2. Если GitHub показывает подтверждение включения Actions, нажмите **I understand my workflows, go ahead and enable them**.
3. В списке выберите **Build HomeGrid RU APK**.
4. Нажмите **Run workflow**, затем ещё раз **Run workflow**.
5. Откройте появившийся запуск. Дождитесь зелёной галочки. Если он завершился красным крестиком, откройте шаг с ошибкой и сохраните текст ошибки.

## Шаг 4. Скачайте APK на iPhone

1. На странице успешного запуска прокрутите вниз до **Artifacts**.
2. Нажмите `HomeGridRU-debug-apk`. GitHub скачает ZIP-архив с артефактом.
3. В приложении «Файлы» нажмите скачанный ZIP, чтобы распаковать его; внутри будет `app-debug.apk`.
4. Передайте APK на Android-телефон (например, через iCloud Drive, кабель или другой способ передачи файлов). Установить APK на iPhone нельзя.

## Если сборка не запускается

- Проверьте, что файл `.github/workflows/android.yml` находится именно по этому пути в корне репозитория.
- Проверьте, что в корне есть `settings.gradle.kts`, `build.gradle.kts`, `gradle.properties` и папка `app`.
- Если сборка падает на загрузке зависимостей, повторите запуск позже; если ошибка повторяется, откройте лог запуска и скопируйте последние строки ошибки.

## Примечания

- Собирается debug APK для тестовой установки, не релизная сборка магазина.
- Android-приложение требует Android 8.0 (API 26) или новее по настройке проекта.
- Сборка требует доступа к репозиториям Google Maven и Maven Central, поэтому временные сетевые ошибки могут помешать сборке.
